# X-Ops Consulting Landing

Bilingual landing page for **X-Ops Consulting**, designed as a continuation of the X-Ops brand under **X-Ops Group**.

## Positioning

**Secure Delivery & Agentic AI Operations. Secure by Design.**

X-Ops Consulting keeps its original operational core and extends it with the new AI-native layer:

- DevSecOps, SecOps and secure software delivery.
- Cloud, Kubernetes, infrastructure as code and platform hardening.
- Secure CI/CD pipelines, SAST, SCA, secrets scanning, container scanning, IaC scanning, SBOM and artifact signing.
- Secure automation, runbooks, observability, alerts and operational workflows.
- Technical training for engineering, security and operations teams.
- Enterprise agentification with secure AI agents and internal copilots.
- Secure RAG, governed knowledge retrieval and document-level controls.
- LLMOps for prompt registry, evaluation, guardrails, observability, red teaming and cost control.
- MLOps and model governance for ML pipelines, model registry, dataset versioning, drift monitoring and secure deployment.
- AI Security and governance across agents, RAG, LLM flows, embeddings, APIs, vendors and policies.

## What is included

- Spanish and English copy.
- Language switcher with local preference persistence.
- Responsive single-page layout.
- Inline dashboard-style hero illustration.
- SVG brand mark included in `assets/logo.svg`.
- GitHub Pages workflow.
- No backend required.

## Recommended brand architecture

- Main group domain: `xopsgroup.com`
- Consulting landing: `xopsgroup.com/consulting`
- Editorial and press: `xops.media`
- Commercial email: `consulting@xopsgroup.com`
